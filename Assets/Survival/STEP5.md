# STEP 5 — SPE·차폐·연구 전력의 영향

## 플레이

게임 시간이 24시간에 도달하면 플레이어 위치나 전력 선택에 관계없이 SPE가 시작된다. SPE(Solar Particle Event)는 태양에서 온 입자로 방사선 환경이 나빠지는 사건이다. 기존 시간·방사선 계산을 사용하며 별도의 타이머를 만들지 않았다.

`Space HUD/HUD Canvas/SPE Warning Panel`은 SampleScene에 직접 저장한 편집 가능한 UI다. 기본 비활성이며 실행 중 SPE가 시작되면 표시한다. 실외에서는 기지 복귀를, 실내에서는 파란 전력 콘솔에 접근해 E키로 조작하도록 안내한다. 콘솔까지의 **직선거리**는 경로 안내나 통과 가능한 길의 길이가 아니다. 방사선 환경은 계속 악화된 상태로 유지되며 경고를 닫거나 안으로 들어간다고 SPE 자체가 끝나지는 않는다.

전력 패널에서 차폐 출력과 연구시설의 할당/개별 전원을 바꾼다. 현재 소비·여유 W, 실제 차폐 출력, 시료 품질이 함께 표시된다. 기존 배분 순서는 필수 생명유지 → 차폐 → 연구시설이며, 연구시설과 장치 우선순위는 전력 정의 에셋에서 바꿀 수 있다. 기본 자동 차단 순서에 더해 개별 장치를 직접 끄고 보존할 연구를 선택할 수 있다. 필수 생명유지 공급은 우선 보호한다.

## 능동차폐

- `Assets/Survival/Shield Rules - Test Model.asset`: 기본 최대 감소율 0.8(80%). 실행 시작 시 복사한다.
- 임시 선형식: **실내 SPE 선량률 = 실외 SPE 선량률 × 기존 실내 투과율 × (1 − 최대 감소율 × 실제 공급 출력)**.
- 요청 출력이 아니라 `PowerBudget.ShieldActualOutput`을 읽는다. 전력이 부족해 실제 출력이 낮으면 보호도 낮아진다.
- 실외와 SPE 이전에는 이 능동차폐가 적용되지 않는다. 실내 벽의 기존 수동 차폐는 그대로 별도 적용된다.
- `ActiveRadiationShield`는 기존 `IRadiationShield`를 구현하며, 향후 근거를 확보한 다른 모델로 교체할 수 있다.
- 피폭 누적, 위험 기준 초과 사망, 48시간 종료는 기존 SurvivalRun을 사용한다. 전력 패널을 여는 동안에도 시간이 흐른다. ESC 일시정지는 누적을 멈춘다.

이 **80%와 선형식은 게임용 임시 모델이며 실제 능동차폐 성능이나 NASA 검증 결과가 아니다**. 기존 방사선량·사망 기준·시간 배속·전력 요구량은 이 단계에서 변경하지 않았다. 기본 수치에서 기지에 계속 머물면 차폐 없이 생존할 수도 있으며, 차폐가 반드시 필요한 최종 밸런스로 검증한 것은 아니다. 실외 활동 시간과 전력·연구 배분에 따른 선택이 가능하고, STEP 6 시나리오 검증과 함께 밸런스를 조절할 수 있다.

## 시료 보존

`Assets/Research/Sample Preservation Rules - Test Model.asset`을 선택해 조절한다. 기본은 연속 냉각 중단 유예 0.5 게임 시간, 이후 시간당 품질 0.15(15%p) 손실, 연구 가능한 최소 품질 0.25(25%)다. 각 보관소의 시료는 독립 상태를 가지며 빈 보관소에는 품질 손실이 없다.

1. 냉각 중단 즉시 신규 유효 보존 시간/데이터 누적은 중단한다. 기존 데이터는 보존한다.
2. 유예시간 동안 품질은 유지한다. 이후 연속 중단 시간에 비례해 품질을 낮춘다.
3. 전력을 복구하면 추가 품질 저하를 멈추고 연속 중단 타이머를 초기화한다. 이미 생긴 손상은 회복하지 않는다.
4. 품질이 최소값 **이하**면 연구불가로 표시한다. 다시 전원을 켜도 신규 연구는 재개되지 않지만 이미 얻은 데이터와 시료 배정은 유지된다.
5. 최소값보다 높을 때 복구하면 유효 보존 시간 누적을 재개한다.

이는 온도·냉각 관성·진공·시료 종류·실제 FROSTE 실험을 계산한 모델이 아니다. 짧은 재냉각으로 유예가 초기화되는 단순화도 포함한다. 필요한 규칙으로 바꿀 수 있도록 독립된 `SamplePreservationState`에 분리했다. 단계별 시간 적분은 게임 시간에서 수행하므로 렌더 프레임 수로 손실을 계산하지 않는다.

측정장비와 식물 구획은 전원 OFF 동안 신규 데이터/유효 시간이 쌓이지 않고, 복구하면 기존 데이터에서 계속한다. 이 단계에서는 식물의 생물학적 손상이나 성장 온도 모델을 추가하지 않았다.

## 파일 역할

- `ShieldRules`, `ShieldEfficiencyModel`, `ActiveRadiationShield`: 교체 가능한 효율 정의·순수 계산·실제 공급 전력 연결.
- `SamplePreservationRules`, `SamplePreservationState`: 품질 정의와 독립 시료 상태.
- `ResearchLedger`, `ResearchProgress`: 게임 시간 적분에 품질을 연결하고 유효한 시료만 신규 성과를 누적.
- `SpeHud`: 씬에 배치한 경고 UI 갱신, 내부/외부 안내·현재 피폭률·현재 조건의 위험 도달 예상 시간·전원 상태 표시. 예상 시간은 현재 피폭률이 유지된다는 조건부 계산이다.
- `PowerPanel`: 기존 전력 UI에 실내 SPE 감소율과 시료별 품질/연구불가 표시.
- `Editor/SpeStepChecks`: 순수 모델 및 기존 씬 통합 검사. `Tools > Space HUD > Run Play Validation`에서 기존 단계 검사와 함께 실행하며 `Run SPE Play Validation`으로 이 단계에 집중해 검사할 수도 있다.

STEP 6에서 최종 결과 화면·종합 점수 UI를 연결했다. 결과 계산과 씬 구성은 STEP6.md를 따른다. 저장·독립 실행 빌드·실제 COM 장치 검증과도 구분한다. 검증 결과는 `QA/SpeStep5/VALIDATION.md`다.
